EYE CIPHER — CORE EXTRACTION SUMMARY
====================================

1. Payload Extraction
---------------------
We isolated the true payload by removing protocol metadata.
The payload consists of 13 trigrams per message.

2. Core Identification
----------------------
Columns 4–8 of the payload contain the semantic content.
These 5 positions form the "instruction core" of each message.

3. Core Structure
-----------------
The Eye Cipher uses a 5-symbol grammar:

    TYPE  MODIFIER  ACTION  TARGET  OUTCOME

4. Column Roles
---------------
C4 = Type (noun class / subject)
C5 = Modifier (property / state)
C6 = Action (verb)
C7 = Target (object)
C8 = Outcome (result)
